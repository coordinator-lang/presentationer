# Nordicta presentationer

Property presentations from Nordicta Corporate Housing. Each presentation has its own link (`/?t=…`); the team's editor is at `/edit/`.

Built files only. The source, the build script and the tests are in koord's project folder `Documents\Nordicta presentationer` (`node build/build.js`).
The page holds only the public anon key; all data is read through the Supabase Edge Function `presentation`.
